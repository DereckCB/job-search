Working

Tailored CVs
One CV per posting, built from a master file. The response rate is above the norm for cold applications, so the CVs get read.
One argument per CV
Pick the sentence the page is arguing and make every section evidence for it.
Honest gaps
Never claim tools or years that are not there. It survives probing.
First interviews
Two for two into a second round. The problem is downstream of here.

Not working

Volume
Cold portal applications have produced no interviews. More is not the answer.
Cold outreach to strangers
Better than a portal, but not the same thing as a warm tie.
No debrief
Rejections are a dataset if written down the same day, and nothing if not.
